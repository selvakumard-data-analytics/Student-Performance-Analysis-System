# Student Performance Analysis System

## Overview

The Student Performance Analysis System is a data analytics project designed to analyze student academic performance and identify the key factors influencing exam scores.

The project uses MySQL for data storage and querying, and Power BI for interactive dashboard creation and visualization. The analysis focuses on attendance, study hours, motivation levels, family income, gender, and other academic factors that impact student performance.

---

## Objectives

- Analyze student academic performance data.
- Identify factors affecting exam scores.
- Compare performance across different student groups.
- Build interactive dashboards for data-driven insights.
- Support educational decision-making through analytics.

---
